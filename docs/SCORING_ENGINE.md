# 六维评分引擎

## 概述

六维评分引擎是系统的核心模块，负责将试卷题目映射到六个能力维度并进行量化评分。

## 六维定义

### 1. 计算熟练度 (Computation)
- **定义**: 口算、笔算、估算等计算能力
- **特征**: 
  - 四则运算速度
  - 计算准确性
  - 简便运算技巧
- **典型题型**: 口算题、竖式计算、脱式计算

### 2. 概念清晰度 (Concept)
- **定义**: 数学概念、定义、符号的理解
- **特征**:
  - 概念定义的准确表述
  - 符号的正确使用
  - 概念间的联系
- **典型题型**: 填空题、判断题、概念辨析

### 3. 逻辑推理力 (Logic)
- **定义**: 数学推理、证明、归纳能力
- **特征**:
  - 演绎推理
  - 归纳推理
  - 逻辑链条完整性
- **典型题型**: 找规律、证明题、逻辑推理题

### 4. 空间想象力 (Spatial)
- **定义**: 几何、图形、空间关系理解
- **特征**:
  - 图形识别
  - 空间旋转
  - 几何关系分析
- **典型题型**: 几何题、图形题、展开图

### 5. 应用实践力 (Application)
- **定义**: 实际问题建模与解决能力
- **特征**:
  - 问题理解
  - 数学建模
  - 结果解释
- **典型题型**: 应用题、实际问题、综合题

### 6. 创新思维力 (Innovation)
- **定义**: 开放题、拓展题的创造性解答
- **特征**:
  - 一题多解
  - 非常规思路
  - 拓展迁移
- **典型题型**: 开放题、探究题、拓展题

## 评分算法

### 基础评分公式

```
维度得分 = Σ(题目得分 × 维度权重) / Σ(维度权重) × 调整系数
```

### 题目-维度映射

每道题目可以映射到多个维度，权重表示该题目在该维度上的代表性。

```json
{
  "question_id": "q1",
  "dimension_weights": {
    "computation": 0.8,
    "concept": 0.2,
    "logic": 0.0,
    "spatial": 0.0,
    "application": 0.0,
    "innovation": 0.0
  }
}
```

### 难度系数调整

```
调整后得分 = 原始得分 × (1 + 难度系数 × 0.1)
```

难度系数范围: -0.5 ~ 0.5
- 难度系数 > 0: 加分（题目难但做得好）
- 难度系数 < 0: 减分（题目简单但做得差）
